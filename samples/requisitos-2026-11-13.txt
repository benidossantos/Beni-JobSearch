O QUE PRIORIZAR NOS ESTUDOS
  1. SQL foi o requisito mais pedido da semana (mais da metade das vagas): pratique consultas com JOIN, GROUP BY e subconsultas em PostgreSQL ou SQL Server.
  2. APIs REST e Git apareceram em metade das vagas: tenha no GitHub uma API simples (FastAPI, Node.js ou .NET) com histórico de commits organizado.
  3. Testes automatizados aparecem em 1 de cada 3 vagas, inclusive nas de QA: escreva testes nos seus projetos e conheça uma ferramenta de automação.
  4. Docker já aparece em 1 de cada 4 vagas: aprenda a criar um Dockerfile e subir sua API com banco usando docker compose.
  5. Para dados, Power BI (DAX e Power Query) e Excel voltaram a aparecer junto com SQL: um dashboard publicado é um bom portfólio.
  6. Várias vagas citam IA (agentes, MCP, RAG, LLMs) como requisito ou diferencial: um projeto pequeno usando a API de um modelo de IA já destaca o currículo.
