O QUE PRIORIZAR NOS ESTUDOS
  1. APIs REST aparecem em quase metade das vagas: saiba criar e consumir uma API do zero (rotas, verbos HTTP, status, JSON).
  2. SQL e Git estão em 4 de cada 10 vagas: pratique consultas com JOIN e GROUP BY, e fluxo de branch e pull request.
  3. Java com Spring Boot é a stack de back-end mais pedida: um projeto CRUD com Spring Boot no GitHub ajuda muito.
  4. No front-end, JavaScript e TypeScript com React dominam: vale migrar um projeto pessoal para TypeScript.
  5. Inglês aparece em 1 de cada 4 vagas, e em quase todas as internacionais.
  6. Testes automatizados (JUnit, Jest, Playwright) são diferencial frequente: inclua testes nos seus projetos.
